# DevAtlas – Website

Dieses Repository enthält die **fertig gebaute Website** von DevAtlas für GitHub Pages – nicht den Quellcode.
DevAtlas ist eine deutschsprachige Lernplattform für Softwareentwicklung und Mathematik: kostenlos, ohne Konto, ohne Werbung, offline nutzbar.
